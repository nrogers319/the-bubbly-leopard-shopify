# The Bubbly Leopard Shopify Theme

Custom Online Store 2.0 theme for The Bubbly Leopard. Design direction: **Champagne Hour**.

## Launch setup

1. Zip the contents of this folder (the zip root must contain `assets`, `config`, `layout`, `locales`, `sections`, `snippets`, and `templates`).
2. In Shopify, open **Online Store → Themes → Add theme → Upload zip file**.
3. The approved primary logo is built in. Add lifestyle photography in the homepage image sections; use **Header → Replacement logo** only if the brand mark changes later.
4. Select a collection in **Featured collection**, then connect each homepage button.
5. Configure the Main menu and footer menus in **Content → Menus**.
6. Test a real order with Shopify Payments test mode before publishing.

The approved primary logo is bundled in `assets/the-bubbly-leopard-logo.png` and appears automatically.
